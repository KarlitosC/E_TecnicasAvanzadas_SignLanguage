# Evaluación 3 – Pipeline optimizado (Sign Language MNIST)

Notebook de la Evaluación 3 de Técnicas Avanzadas de Machine Learning (TLY1102).

El proyecto compara una red MLP y una CNN para clasificar las vocales A, E, I, O y U. Incluye Pipeline Integrado, regularización, optimización de hiperparámetros, evaluación, pruebas de robustez con y sin Data Augmentation, auditoría y explicabilidad (Grad-CAM).

**Notebook:** [TLY1102_E3_Final.ipynb](TLY1102_E3_Final.ipynb)

## Ejecutar en Google Colab

1. Abrir el notebook en Google Colab.
2. Subir `sign_mnist_train.csv` y `sign_mnist_test.csv` al panel de archivos.
3. Ejecutar las celdas en orden y revisar sus salidas.

Los CSV no se duplican aquí; se obtienen del material utilizado en la asignatura.
